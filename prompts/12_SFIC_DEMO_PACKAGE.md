# Prompt 12 — SFIC demo package

Prepare reproducible SFIC materials:
- `sfic/problem_statement.md`
- `sfic/technical_summary.md`
- `sfic/demo_script.md`
- `sfic/limitations_and_validation.md`
- `sfic/estimated_costs.md`
- `sfic/team_task_split.md`

Explain the problem, user need, approach, optimizer, simulation, benchmark, data provenance, and validation plan in clear language. Separate demonstrated results from hypotheses and future work. Label synthetic outputs prominently. Include limitations, risks, and what real farm data/subject-matter review would be required. Never fabricate interviews, survey results, savings, model accuracy, or field validation. Include a short demo fallback if the app fails. Stop for human review.
