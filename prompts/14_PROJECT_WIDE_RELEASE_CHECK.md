# Prompt 14 — Project-wide release check

Review the project against `README.md`, `docs/PROJECT_ROADMAP.md`, and all acceptance criteria. Check that setup works from a clean environment, dependencies are justified, tests are executed, data provenance is documented, synthetic data is clearly labelled, and all claims are supported.

Produce a release checklist and concise report covering:
- implemented vs not implemented;
- test commands and actual outcomes;
- known bugs and limitations;
- reproducibility steps;
- performance on the target PC or what remains unverified;
- SFIC demo readiness and fallback;
- next three actions.

Do not mark the project production-ready or scientifically validated unless evidence supports that status. Do not begin new feature work during this audit without approval.
