# Prompt 13 — Debugging protocol

Investigate the reported issue before changing code. Reproduce it if possible, identify the root cause, and propose the smallest safe fix. Preserve architecture and existing working behavior. Add a regression test. Do not suppress exceptions, weaken validation, or hard-code a passing result just to remove the error. Run relevant tests and report exact commands and outcomes. If the cause is uncertain, state what is known and what evidence is missing.
