# Prompt 10 — Minimal dashboard and reports

Build a minimal working interface only after the core optimizer, validation, and any justified simulation experiments are stable. Suggested sections: overview, ingredient data/provenance, goat/group profile, optimization, scenario simulation, benchmark results, data quality, export/report.

Every control must work and every chart must use actual application results. Do not use fake charts, invented numbers, decorative controls that imply functionality, or unlabelled synthetic data. Include loading, empty, validation-error, and infeasible-plan states. Keep the interface lightweight and functional on the target PC. Add smoke tests and document setup. Stop for review.
