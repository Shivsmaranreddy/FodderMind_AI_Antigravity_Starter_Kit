# Working Rules for Antigravity

You are helping build FodderMind AI, a lightweight, evidence-conscious goat fodder planning prototype.

## Non-negotiable rules
- Work in small phases. Do not implement the entire application in one pass.
- Read `README.md` and `docs/PROJECT_ROADMAP.md` before acting.
- Start by inspecting the existing repository. Preserve user work.
- Do not delete, overwrite, or perform destructive actions without explicit approval.
- For architecture-changing decisions, present options and trade-offs and wait for approval.
- Keep the initial stack CPU-friendly for Windows 10 64-bit, Intel Pentium G4400 (2 cores), 8 GB RAM, SSD.
- No GPU, paid API, cloud dependency, or credit card requirement for the baseline prototype.
- Prefer simple, tested tools over fashionable complexity.
- Do not add deep RL, MADRL, deep learning, computer vision, or IoT integration unless a documented experiment or requirement justifies it.
- Never invent sources, animal requirements, ingredient composition, farm observations, interviews, costs, benchmark results, or validation outcomes.
- Clearly label synthetic/simulated data. Never describe synthetic outputs as real farm measurements.
- Missing values must not silently become zero. Track units, basis, source, date, and evidence status.
- Nutritional and other safety constraints must be independently validated; a reward penalty alone is not a safety guarantee.
- Do not claim biological effects (growth, milk yield, health, welfare) unless a suitable validated model and evidence support them.
- Never claim a test passed unless it was run and passed. Report command, result, and failures.
- Keep experiments reproducible with configuration, random seeds, versioned methods, and logged metrics.
- Avoid huge simulation dumps; batch logs and store concise summaries.
- At the end of every phase, report: files changed, commands run, tests and actual results, assumptions, blockers, risks, and next three actions.
- Stop at the phase boundary and request approval before starting the next major phase.
