# Prompt 09 — Robustness and sensitivity analysis

Design and run bounded sensitivity experiments for feed prices, availability, budget, and nutrient composition uncertainty only where plausible ranges can be sourced or clearly labelled as assumptions. Update `docs/experiments/sensitivity_plan.md`.

Measure changes in cost, feasibility, selected quantities, binding constraints, and policy behavior. Include adverse scenarios and cases where no feasible plan exists. Do not represent assumed ranges as measured farm distributions. Keep runs small enough for the target PC, use fixed seeds, and record configuration and results. Stop and report limitations.
