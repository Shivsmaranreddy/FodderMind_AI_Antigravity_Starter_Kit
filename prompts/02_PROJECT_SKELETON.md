# Prompt 02 — Project skeleton

After architecture approval, create only the minimal skeleton needed for the approved design. Prefer Python, a lightweight API (FastAPI only if justified), SQLite, NumPy/pandas only where needed, and a simple HTML/CSS/JS frontend. Keep modules separate: data, optimization, simulation, RL, validation, reporting, API.

Add setup instructions, `.gitignore`, `.env.example`, dependency manifest, a health endpoint if an API is approved, and basic smoke tests. Do not add heavy ML frameworks or paid services. Do not implement placeholder features that pretend to work. Run available tests and report exact results. Stop at the phase boundary.
